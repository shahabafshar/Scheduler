# How to Run the Real-Time Scheduling Simulator

## Quick Start

```bash
# From project root
streamlit run scheduler/app.py

# Or from scheduler directory
cd scheduler
streamlit run app.py
```

## Features Available

✅ 7 Scheduling Algorithms (RMS, EDF, DMS, LLF, Polling, Deferrable, Sporadic)
✅ Interactive Gantt Charts
✅ Metrics Dashboard (4 charts)
✅ 6 Preset Examples
✅ CSV Export

See `scheduler/COMPLETE_STATUS.md` for full details.
